# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **Security Log Analyzer**, please do not open a public issue.
Contact our security coordination team at `security-alert@security-analyzer.local`.

All security vulnerabilities will be acknowledged within 24 hours with an initial severity triage and remediation plan.
